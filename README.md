# 🌍 Contexto Expandido

## Objetivo

Contexto Expandido es un espacio donde las ideas encuentran un lugar para crecer.

Este proyecto reúne áreas como desarrollo de software, idiomas, música, viajes y aprendizaje continuo. Además de servir como portfolio personal, es un laboratorio donde experimento con nuevas tecnologías, APIs, diseño y buenas prácticas de desarrollo y QA.

---

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS

---

## Estado actual

Actualmente el proyecto cuenta con:

- Landing page funcional.
- Hero con imagen de fondo y overlay.
- Componentes reutilizables.
- Navegación entre páginas.
- Layout compartido.
- Scroll suave entre secciones.
